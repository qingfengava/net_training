# 烘焙 v3：对齐运动模糊、预测 ROI 与点阵采样

2026-11-05：已实现数据生成流程，尚未训练增强后的模型，也未用实拍拟合参数。代码位于 [bake_augment.py](../nt/bake_augment.py)，由 [nt.bake](../nt/bake.py) 接入。

## 配置与使用

| 配置 | 中心对齐模糊核 | 预测 ROI 扰动 | 摩尔纹 |
|---|---|---|---|
| configs/bake/default.yaml | 开启 | 关闭 | 关闭 |
| configs/bake/tracker_roi.yaml | 开启 | 开启 | 关闭 |
| configs/bake/moire.yaml | 开启 | 关闭 | 35% 图像尝试启用 |
| configs/bake/tracker_moire.yaml | 开启 | 开启 | 35% 图像尝试启用 |

两项新增强默认只处理 source=sim 且实际分区为 train 的样本。真实图像不会被重复添加；验证分区继续使用修正模糊核后的基础烘焙。train_only=false 可生成单独的合成压力验证集，但不能把这种验证当作真实域收益。

小批量检查命令：

~~~bash
scripts/run_capped.sh 3 -- python -m nt.bake \
  --src datasets/sim/style_b_train \
  --src datasets/sim/style_b_val \
  --config configs/bake/tracker_moire.yaml \
  --out baked/style_b_tracker_moire_preview \
  --copies 2 --seed 0 --workers 2 --limit 12
~~~

确认样本后，去掉 --limit 并换一个新输出目录，才能生成完整数据集。烘焙不启动训练，输出目录存在时会拒绝覆盖。四组消融使用相同源数据、种子、训练设置和独立验证会话；不要让“修正模糊核”与“增加两项增强”的影响混在一起。

## 运动模糊的对齐修正

旧算法在任意整数尺寸的核上绘制整数端点线段。偶数核中心与 OpenCV 默认锚点不一致；线段端点舍入也能令部分奇数核不对称。

centered_v1 使用奇数支撑域，在连续线段上采样，通过双线性权重分配到核网格，再强制核与其中心翻转的平均，归一化后显式使用中央锚点。配置的长度仍可取 2～9，偶数长度无需删除；长度控制线段跨度，不再直接决定矩阵边长。

该修正适用于新烘焙，不会修改已有 PNG 或历史标签。新清单的 bake_version 为 3，配置及逐图效果记录保存核算法。

历史清单的 effects.motion_blur 没有 kernel 字段时，prepare_view 仍执行原 legacy_v2 路径，保持随机序列、舍入及操作顺序。复现旧实验时应读取其原清单中的整个配置，不能把今天的默认配置合并进去。也可显式指定 kernel=legacy_v2，仅用于历史对照。

## 预测 ROI 扰动

这个模块模拟网络看到的窗口分布，不运行 sleepy 跟踪器，也不增加部署推理次数。合成路径用当前装甲为位置和尺度参照，采样整车装甲包络的近似大小，再施加预测残差；未宣称已经复现连续跟踪误差。

默认状态抽样：

| 状态 | 概率 | 输入 |
|---|---:|---|
| 搜索 | 35% | 全图 |
| 巡检 | 5% | 全图 |
| 短暂恢复 | 20% | 带较大误差和扩窗的 ROI |
| 稳定跟踪 | 40% | 带预测残差的 ROI |

状态比例是待校准的实验设置，巡检是计划中的部署策略，不代表 sleepy 当前已经实现巡检。非 4:3 源图的“全图”会使用能容纳的最大居中 4:3 区域。

- 包络尺度：装甲投影宽高包络的 2～5 倍；普通目标再扩 1.4 倍，基地扩 3 倍。没有实例 ID 时不按编号把不同机器人错误地合并。
- 时间间隔：稳定状态 2～20 ms，恢复状态 20～300 ms。
- 位置误差：包络尺度相关的高斯误差，加上“速度预测误差 × 时间间隔”。速度误差以画幅/秒配置，再换算为原图像素/秒。
- 尺度误差：对数尺度随机偏差；恢复时位置误差随时间增加。
- 窗口按 lost_time_ms=1500 线性扩大到最大范围；超时或预测中心离开图像时回全图。这与现有 sleepy 时间扩窗机制对应，后续改变运行时回退阈值时应同步调整数据配置。
- 输出保持 4:3，触边时平移窗口，适配本项目 768×576 输入。它不照搬旧 RP 分支的最终正方形窗口。

预测窗口不以当前真值是否成功覆盖目标作为重抽条件。与窗口相交的装甲保留标签，出窗角点的 vis 设为 0；完全没有面交集的目标才移除。这样允许部分截断和真实漏裁，不把半块装甲当作无标注背景。严重截断的类别可辨认性仍应在数据审核时检查。

### 使用回放预测包络

仿真样本可在 canonical 的 scene.roi_prediction 中提供外部预测，替代随机误差路径：

~~~json
{
  "image_size": [1440, 1080],
  "bbox": [620.0, 420.0, 820.0, 560.0],
  "age_ms": 18.0,
  "state": "tracking",
  "is_base": false
}
~~~

bbox 是当前图像时间、原图像素边缘坐标下的预测包络 [x0,y0,x1,y1]，尚未进行固定扩边和时间扩窗；不能直接填最终 ROI。state 支持 tracking/recovering/search/patrol。记录应由回放或采集适配层生成，当前普通 sleepy 日志不会自动转换成这些字段。本入口仍遵循仿真源与训练分区限制。

如果同一帧又开启新增镜头畸变，包络的坐标系就不一致，因此明确报错，不猜测变换。meta.jsonl 中的 roi_augmentation 保存来源、状态、时间、预测误差及边界平移。

## 点阵与相机采样产生的摩尔纹

实现为 dot_sampling_residual_v1，在已渲染图像上叠加有采样依据的有限幅度亮度残差：

1. 根据装甲四角点建立平面到图像的单应变换，得到点阵相位和局部投影频率。
2. 用有限傅里叶展开表示方点或圆点网格。
3. 用高斯光学传递函数衰减高频，并用像素孔径的 sinc 响应积分。
4. 在原图像素中心采样，由超过奈奎斯特频率的成分形成混叠，再将有限幅度增益应用到亮屏区域。

这不是直接覆盖几条固定频率条纹。倾角、距离、点阵布局、相位、光学模糊和像素孔径都会影响纹理。光学模糊足够强或点阵非常小时，模型会自然衰减，可能没有可见变化。

默认强度 0.15～0.35，光学 σ 为 0.15～0.45 原图像素，像素孔径为像素间距的 0.6～1.0。每通道使用相同亮度增益；不移动角点，不人为改变红蓝类别。熄灭屏和带遮挡标记的装甲跳过，避免在遮挡物上绘制点阵。增强先作用在原分辨率裁剪图，然后继续现有曝光、光晕、模糊、噪声和最终缩放。

默认从 scene.screen 的 look 读取实际行列数和点形状。若没有屏幕元数据，或者同帧有不同点阵布局且无法关联到各块装甲，会记录原因并跳过，避免将 B 的 64×48 强加到 A 上。已知数据集布局时可显式设置 grid_source=config，用 grid 和 dot 指定；填充率仍从配置范围抽样。

它是残差近似：输入已经经过仿真渲染，无法恢复丢失的子像素字形；当前不模拟完整 RAW/Bayer/去马赛克链路，也不模拟显示刷新、PWM 时序或滚动快门。是否提高实拍精度，必须使用独立相机会话验证。

effects.moire 保存点阵、相位、填充率、光学参数、增益范围及实际改变的像素通道数。images_with_moire 统计在这一增强步骤确实改变了值的图像数；后续模糊和量化可能进一步减弱变化。
