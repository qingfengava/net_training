# 装甲板标注规范

给拿到标注批次的同学看。每个批次是一个文件夹，里面有图片、同名的 `.json` 标注文件和 `batch.json`。`batch.json` 不要改。

## 准备

装一次 labelme（版本要一致）：

    pip install labelme==6.3.1

在本仓库里也可以运行 `scripts/setup_labelme.sh`，它会把 labelme 装进单独的 `.venv-label`。

打开一个批次：

    labelme annot/项目名/batch_000 --config annot/项目名/labelme_config.yaml --nodata --autosave

一定要带上 `--config`。它固定了标签列表和勾选项，打错标签的时候 labelme 会直接拒绝。

## 标什么

每块看得到的装甲都要标，包括很远的、很暗的和被挡住一部分的。少标一块，等于告诉网络"这里没有装甲"，比标得不准危害更大。

装甲画成**多边形**，正好 4 个点，**按固定顺序点击**：

1. 左上
2. 左下
3. 右下
4. 右上

这里的"左、上"指装甲自己的左上，也就是正着看这块装甲时的左上角，不是图片的左上。装甲倾斜时也按这个规则。

角点是什么位置，以 `configs/label_spec.yaml` 里的 `corner_definition` 为准。RM27 的样式公布之前，用的还是灯条端点：左右两根灯条的上下端。

标签名写成 `颜色_编号`，比如 `red_three`、`blue_sentry`、`blue_outpost`。从列表里选，不要手打。

RM27 只有小装甲模块，不用标尺寸。

## 被挡住和出画的角

- **被挡住、但能估计位置的角**：在估计位置把多边形的点放好，再在这个角上放一个 `occluded` 点（点工具）。
- **出了画面的角**：labelme 不能把点放到图外，就把这个角的点放在图片边缘，再在这个角上放一个 `outside` 点。

这两种点必须落在对应的角上（几个像素以内），否则自检会报错。

## 预标注

批次里一般已经有模型画好的框，你的工作主要是改：

- **普通标签**：模型比较有把握的。检查四个点的位置、顺序和标签，错了就改，画的不是装甲就删掉。
- **`?` 开头的标签**：模型没把握，或者几何形状可疑，或者装甲被图片边缘切断。必须处理：是装甲就改成正式标签（双击形状，从列表选），不是就删掉。只要还剩一个 `?`，这一帧就不能入库。

形状的说明里有 `auto conf=0.83` 这样的字样，是模型给的置信度，只作参考，不用改。

## 一帧做完

- 检查完这一帧的所有装甲后，勾选右上角的 `reviewed`。**没勾的帧不会入库**，所以宁可漏勾，也不要没看完就勾。
- 图片本身不能用（花屏、全黑、糊得分不清）的，勾选 `bad_frame`。
- 一块装甲也没有的帧也要勾 `reviewed`。它会作为负样本入库，同样有用。

## 自检

交回之前运行：

    python -m nt.annotate check annot/项目名

它会列出所有入库时会被拒绝的问题，比如点的顺序反了、点数不是 4、还有 `?` 标签、遮挡点不在角上。全部改到没有报错再交。

## 常见错误

- 从右上角开始点，或者顺时针点。自检会报 `E_QUAD_ORDER`。
- 把相邻的两块装甲合成一块，或者只框了半块（一根灯条加半个数字）。
- 远处的小装甲没标。
- 颜色标反。灰色（熄灭）装甲标成 `gray_编号`，不要标成红或蓝。
